00GRID.APP  ·  v1.0.0

GRID

A terminal-first workspace for macOS.

A real terminal, a file browser, an app launcher, a widget deck, a web browser and an offline map in one keyboard-driven window, styled after the production design of Tron: Legacy and Tron: Ares.

Download v1.0.0 ↓ Source on GitHub ↗ Release notes ↗

  • Swift 6
  • SwiftUI + AppKit

01Why GRID.CORE

Terminal first

Your real login shell in a native terminal, with tabs, splits and find. Everything else sits around it.

One keystroke away

Files, apps, settings and web pages all open from the command palette (⇧⌘P). Every shortcut can be changed.

Native and light

Swift, SwiftUI and AppKit, with WebKit for the browser. No Electron, no background services.

Private by default

No accounts, no telemetry, no cloud. Your data stays on your Mac.

02Features.SYS

02.1Terminal + Files

A real shell, with your files beside it.

  • Your login shell with your PATH and dotfiles, in tabs and split panes (up to six per tab).
  • Find with case, regex and whole-word options; busy, done and bell indicators on tabs.
  • A file browser that expands folders in place, or shows them as an icon grid that traces itself in.
  • Drag files in safely: dropped paths are inserted quoted and are never run for you.
02.2Workspace

Arrange it your way.

  • Dockable panels: drag Files, Terminal or the Widget Deck to any edge. The layout is saved.
  • Widget deck (⌘J): clock, system, network, storage, power, git, notes and more, all real measurements.
  • Now Playing redraws cover art in your theme’s colour as a dot matrix or scan lines.
  • Build your own widgets with a manifest.json and some JavaScript. They run sandboxed.
02.3Browser

The web, in GRID’s style.

  • A full WebKit browser with tabs, search, find, zoom and history.
  • Site themes give GitHub, Hacker News, MDN, Wikipedia and more GRID’s colours and type.
  • Reader view (⇧⌘R) re-sets articles in a monospaced layout.
  • Ad blocking with uBlock Origin’s default lists, and WebExtension support on macOS 15.4+.
02.4Palette + Themes

Everything from one prompt.

⇧⌘P opens the command palette for commands, apps, folders and web addresses. It understands a small grammar, and its commands are never sent to your shell.

03Map.GEO

03.1Directions

Routes that avoid mapped ALPR cameras.

GRID draws its own map on the GPU: glowing roads, wireframe buildings, 3D terrain and a globe when you zoom out. It shows licence-plate reader cameras mapped by OpenStreetMap volunteers (via DeFlock).

  • Two routes: the fastest, and one that avoids the mapped cameras it can, with turn-by-turn steps.
  • Worked out on your Mac: start points, destinations and routes are never sent anywhere.
  • Print a route, save it as GPX, or copy it as text.

04Install.PKG

04.1Download
  1. Download GRID-x.y.z-macOS.zip from the latest release, unzip it and move GRID.app to Applications.
  2. GRID isn’t notarized by Apple yet, so macOS blocks the first launch. Open it once, then go to System Settings › Privacy & Security and click Open Anyway. You only do this once.
  3. Optional: check the download against the .sha256 file from the same release.
shasum -a 256 GRID-1.0.0-macOS.zip

Requires macOS 15 Sequoia or later (browser extensions need 15.4) on Apple silicon. GRID can check for updates once a day if you turn it on, and never replaces itself.

04.2Build from source

Needs Xcode 16.3 or later. Swift Package Manager fetches the rest.

$ git clone https://github.com/max-pasho/grid.git
$ cd grid
$ scripts/bundle.sh   # → build/GRID.app
$ open build/GRID.app

05Privacy.SEC

  • No accounts, telemetry, cloud services or AI features. Settings, browsing data and history stay on your Mac. Terminal contents are never logged or stored.
  • Maps are opt-in. Nothing downloads until you click Enable Map Data, and every camera or road-data download asks first, with the host and size.
  • Web content is isolated. Pages can’t reach your terminal, files or apps. Downloads are confirmed and quarantined like Safari’s.
  • Widgets are sandboxed in a separate locked-down process, with permissions shown in plain words.
  • macOS protections stay on. GRID never tries to work around macOS privacy prompts.
